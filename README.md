# Caroez | Skin Atelier

Welcome to the official repository for **Caroez | Skin Atelier**, an exclusive skincare and aesthetic consultation atelier based in Guadalajara, Mexico. 

This repository contains the source code for the brand's landing page, service menus, and direct contact options.

---

## Brand & Design

- **Primary Color:** Deep Plum / Burgundy (`#7D0B59`)
- **Accent Color:** Lime Green (`#B1D235`)
- **Typography:** Elegant, modern serif and sans-serif fonts
